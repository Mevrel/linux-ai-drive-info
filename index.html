Linux AI Drive is a personal setup using rclone to transfer files between the owner’s Linux computer and Google Drive. It is not a public service and does not accept registrations.

What the connection does

It reads existing Drive files and metadata, compares copies, and uploads selected local files. The intended configuration makes Linux the main working copy, backs up replaced cloud files, and performs no automatic destination deletions.

Access and control

The Google Drive authorization permits reading, creating, modifying, and deleting files across Drive. The transfer configuration restricts the operations performed; it does not narrow the underlying Google permission. The owner can revoke access through their Google Account.

This website is informational. It has no Google sign-in feature and accepts no file uploads.
