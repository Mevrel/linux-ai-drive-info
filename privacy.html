Linux AI Drive

Privacy policy

Effective 17 September 2026.

Scope

This notice covers the personal Linux AI Drive file-transfer connection using rclone. It does not cover separate AI tools or other applications that the owner may authorize to use local files.

Data and purpose

The connection accesses file contents and metadata, including names, folder structure, sizes, modification times, and checksums, to transfer files, compare copies, and verify transfers. Listings may include metadata beyond individual transferred files.

Storage and sharing

OAuth credentials and tokens, downloaded files, and transfer records are stored on the owner’s Linux computer. Uploads and cloud backups are stored in the owner’s Google Drive. The transfer connection exchanges data between that computer and Google; it does not itself send files to AI models, advertisers, or data brokers.

Retention and removal

The owner controls retention of local copies, logs, and cloud backups. Access can be revoked through Google Account third-party connection settings. Revocation does not delete existing copies: local files, saved credentials, and cloud files must be removed separately if no longer wanted.

This website

This informational site has no registration, Google sign-in, upload form, or added analytics scripts. GitHub Pages hosts the site and logs visitor IP addresses for security purposes. See the GitHub Privacy Statement.

Contact

Contact the maintainer through this repository’s issues. Issues are public: do not submit private files, credentials, or sensitive personal information.
